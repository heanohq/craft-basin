# Security policy

## Reporting a vulnerability

Please don't report security issues in public issues.

Report them privately through GitHub instead: on this repository's **Security** tab, click **Report a vulnerability**. Only the maintainer can see the report.

Please include:

- the plugin, Craft and PHP versions
- what an attacker could do, and what they'd need (a Control Panel login, a particular permission, nothing)
- steps to reproduce it

You'll get a reply within a few working days. Once a fix is released, the advisory is published with credit to you, unless you'd rather not be named.

## Supported versions

Security fixes are released for the latest 1.x version.
